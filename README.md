# Fill It Now

**A time-saving Chrome extension that auto-fills repetitive job application forms with your saved profile information — in just one click.**

Tired of entering the same details over and over again? **Fill It Now** helps you breeze through job applications by auto-filling forms using the data you provide — securely stored in your browser. It's fast, private, and customizable.

## ✨ Features

-   Auto-fill job application forms with a single click
-   Fully customizable profile fields
-   Data stays private — stored only in your browser

## 🛠️ How to Use

1. **Set up your profile:**

    - Right-click the Fill It Now extension icon in the Chrome toolbar and select **Options**
    - Enter your profile information (name, email, LinkedIn, etc.) and save

2. **Autofill forms:**
    - Visit any job application or registration form
    - Click the extension icon-your saved info will be auto-filled
    - The icon will update if autofill was successful

## ⚙️ Installation

1. **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/fill-it-now.git
    ```
2. Open Chrome and go to: `chrome://extensions/`
3. Enable **Developer Mode** (top-right corner).
4. Click **"Load unpacked"** and select the project folder.
